# 0002 3D 姿态渲染使用 SceneKit

## 决策

使用 SceneKit 实现 [F-005](../prd.md#f-005) 的 3D 姿态渲染。

## 依据

- 需求：[F-005](../prd.md#f-005)。
- 渲染对象是简化几何体，姿态由传感器数据驱动朝向，不涉及摄像头画面叠加或 AR，是纯离线可视化回放。
- iOS 上可选的原生 3D 框架主要是 SceneKit 和 RealityKit。SceneKit 的 API 直接，文档和参考资料丰富，对渲染一两个简单几何体、随时间轴拖动更新朝向的需求，性能完全够用，落地更快。

## 备选方案

### RealityKit（未采纳）

苹果主推的现代 3D 框架，基于 Metal 做了更底层的优化，将来做 AR 叠加时迁移路径更顺。但它面向 AR 场景，采用 Entity-Component 架构，API 更抽象；对当前需求这层抽象是不必要的复杂度。当前需求不涉及 AR。

## 影响

- 能快速实现离线回放的姿态渲染。
- 如果后续要做 AR 叠加（如把 3D 姿态叠加在实时摄像头画面上），SceneKit 在这类场景下能力较弱，届时需要重新评估渲染引擎。
