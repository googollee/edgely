# 0015 传感器电量按左右脚分两半显示，连接页显示在设备行里

## 决策

电量只用"标签 + 百分比"的文字显示；校准后的页面在一行里按左右脚分成两半显示；连接页不用顶部电池条，把百分比放在设备选择行的最左侧；校准过程不显示电量。

### 各阶段的显示

| 阶段 | 显示位置 | 内容 |
| --- | --- | --- |
| 连接（设备选择） | 每个设备行的最左侧 | 仅百分比 |
| 校准 | 不显示 | — |
| 准备录制、录制中 | 页面顶部，一行分左右两半 | "左脚 85%"、"右脚 72%" |
| 历史、回放 | 不显示 | — |

### 校准后的一行两半布局

- 一行等分成左右两个槽位，各占一半宽度。左脚传感器放左半边，右脚传感器放右半边，与发现或连接的先后顺序无关。
- 每个槽位内容靠自己那一半的左侧对齐：标签（"左脚"/"右脚"）在前，百分比在后。
- 只有一个传感器时，它仍只占自己那一半，另一半留空，不撑满整行。
- 万一有传感器没有判定出左右脚，放到还空着的那一半。

### 百分比与颜色

- 不再画电量条，只显示百分比文字。
- 电量 ≤ 10% 时百分比用红色，其余用主色。只有百分比变色，标签不变色。
- 已连接但还没读到电量时显示 `--%`，不算低电量。

### 断线时

- 不显示百分比，也不保留最后一次读到的值。
- 校准后的页面：槽位保留，显示"左脚 已断线"（或"右脚 已断线"），让用户知道是哪只脚的传感器掉了。
- 连接页：该设备行不显示电量（设备断线时本来就不能使用）。
- 重连后收到新的电量之前显示 `--%`，不显示旧值。

### 不变的部分

- 电量读取方式不变：传感器就绪时立即读一次，之后每 60 秒轮询；录制自己的每分钟电量快照也不变。
- 只针对传感器，不含手机电量，没有震动、声音等其他提醒。
- 不拦截任何操作。

## 依据

- 需求：[F-013](../prd.md#f-013)。
- 此前的电池条挂在根视图顶部，连接、校准、准备录制、录制中四个页面共用。每个被监控的传感器占一行，内容是称呼、电量条、百分比，断线时加"已断线"；断线后校准、录制页继续显示最后读到的电量。这带来几个问题：
  - 两个传感器占两行，挤占页面高度。
  - 一行里的元素（称呼、120 宽电量条、百分比、"已断线"）在手机屏幕的一半宽度里放不下，没法并排。
  - 左右脚的位置信息没有体现在布局上，用户要读文字才知道哪个是哪只脚。
  - 连接页还没有判定左右脚，称呼只能用设备名；校准期间的页面本来就在专注于传感器摆放和动作，电量条是干扰。
  - 断线后保留最后一次电量的意义有限：断线本身已经足以提示用户检查传感器，保留的数值反而可能被误当成当前电量。

## 备选方案

### 保持每个传感器一行，只缩短标签（未采纳）

改动最小。但仍占两行，左右位置没有体现在布局上，高度和位置对应这两个问题都没解决。

### 保留电量条，每个槽位里分上下两层（未采纳）

保留图形化显示，一眼能看出大致剩余量。但槽位高度翻倍，电量条宽度要随屏幕自适应；电量本来只有 12 个档位，图形比数字多提供不了多少信息。百分比文字加颜色已经足够，一行更简洁。

### 断线后继续显示最后一次的电量（未采纳）

传感器没电关机时，用户能看到"最后是 0%"，直接知道原因。但旧数值可能被误当成当前电量，也与"断线就显示已断线"的状态表达重复。断线本身已是需要处理的信号；录制自己的电量快照保留了断线前的电量，事后可以查。

## 影响

- 电池条只占一行，左右位置一目了然，校准期间页面更干净；连接页的电量紧挨着对应的设备，不用再靠称呼对应。
- 校准期间看不到电量；传感器在校准过程中没电关机时，用户要等到校准结束才能看到"已断线"。
- 断线后看不到最后一次的电量，没电关机的原因只能事后看录制的电量记录。
- 连接页的设备行要接入电量数据；顶部电池条在连接页不再出现，也就不再有"第一个传感器连上时页面下移一次"的现象。
